# Native prepared inputs

The privileged helper prepares Recovery and the Neo's model-wide firmware before launching disk installation. Paths and signing requirements come from the helper, never from GUI request fields.

- The GUI supplies a bounded flat container of its signed Recovery template. The root importer checks size and digest, reconstructs regular files, verifies the helper's signing policy, and durably publishes a template for later account and shutdown operations. The original authenticated source-owner identity is checked before mutation and again when staging.
- Neo firmware uses the compile-embedded, authenticated J700 range recipe through `AuroraFirmware`. A private namespace per recipe retains verified HTTP ranges across interruption. Published outputs are validated again by the extractor on reuse. Other boards keep their existing preparation path until a native recipe is qualified for them.
- Swift converts the Neo camera, radio and ALS inputs before partition changes. It reads the running Mac's factory calibration, Bluetooth address and ALS record directly, validates supplied regulatory policies, and publishes a private snapshot beside the imported job. The snapshot binds every file to the job, plan, metadata, payload, recipe and local-input hashes. Each attempt collects local inputs afresh; converted calibration never enters the reusable model-wide cache.
- The backend consumes the converted bytes without repeating camera, radio or ALS collection and conversion. The snapshot is removed when execution returns, including failures. Interrupted attempts retain the original job and verified raw download cache; they prepare a new converted snapshot on retry.
- The runtime advertises `helper-template-v1`, `helper-raw-v1` and `nativePeripheralInput: helper-converted-v1`. An incompatible engine fails before execution rather than silently ignoring native inputs. Neo installation requires the converted contract. The plan digest uses the engine's bare hexadecimal format; binding and artifact identities retain their `sha256:` prefix.

An initial, terminal failure with a helper-attested absence of disk changes may clear only its matching GUI lookup hint and allow a newly reviewed plan. Recovery retries, interrupted workers and failures after mutation retain their original context. A Recovery authorization retry reuses the original package and does not restart firmware downloads.

Account preparation and shutdown handoff send the authenticated app's current flat Recovery container with the existing target ticket. After revalidating that target, the helper verifies the container against its own current signature policy and durably refreshes the retained template under the same job gate as the target update. Installing a newer app can therefore update Recovery without a new disk plan or replaying installation. Inspection and finalization reject unexpected template inputs; a missing or invalid update cannot replace the retained copy.

Plan construction now runs in Swift through `NativeInstallerPlanner`, using the freshly validated inspection already acquired by the app. It rechecks the selected extent and produces the same plan digest and transcript contract consumed by the existing catalog review and owner approval. A completed or already planned transcript cannot stand in for a fresh inspection. Synthetic fixtures are generated independently by the retained engine contract and checked by both the portable suite and native tests.

Initial inspection and the fresh pre-plan inspection now use `NativeInstallerInspector`. It collects the internal disk’s partition and APFS graph through fixed system queries, checks each System/Data group, reads existing systems through verified read-only volume access, and verifies that the graph did not change during collection. Temporary mounts have a separate bounded cleanup path that still runs after cancellation. Native geometry and firmware-size selection are compared with synthetic reference vectors generated from the authenticated retained runtime’s public source. The initial inspection policy is compiled into the app; pre-plan requirements come from the selected catalog-authenticated metadata. Public catalog model qualification remains independent of backend capability.

The normal on-demand app no longer bundles the reference runtime used by developer qualification tools. It stages its execution engine from the selected signed catalog. Explicit private/offline bundles retain their authenticated-engine checks, including engines carried under the offline artifact directory. Packaging signs the Recovery template with hardened runtime before sealing its final hash in the helper configuration.

The disk-installation backend still uses the existing engine adapter. Native country-policy generation, the remaining firmware collectors and the full Swift disk backend remain unfinished. Existing signed policy inputs are validated during preflight; missing policy is not bypassed. Fresh-install and Recovery hardware qualification remains separate from native component tests. The legacy existing-install candidate contract still recognizes its original EFI label; recognizing every Aurora distribution’s generated label needs a matching admission update before that gap can be considered solved.

The auxiliary decoder is packaged separately in `Contents/Helpers`, where application signing reaches it. Its unsigned bytes must match the reproducible build record before signing. The GUI copies that executable through the existing FD package contract; the root importer checks bounded bytes and digest, makes its copy executable, and revalidates it in place on retained-job retries. Before execution the helper checks the signature against its own exact development pin or fixed identifier and Developer ID team policy. The engine receives only that verified path and requirement and verifies them again before use. It has no bundled-decoder fallback. A runtime capability check rejects older engines that cannot consume this contract, and the engine producer refuses native code beyond the authenticated runtime inventory.
